## Bytenight Cybersecurity Workshop - Attacking LLM: Prompt Injection

Date: 21-5-2026
Venue: Male Student Lounge, KICT

This workshop is a beginner-friendly guide to AI security, designed for those who want to learn how attackers make AI misbehave and how we stop them. We will explore AI vulnerabilities, the OWASP LLM Top 10, and defense-in-depth strategies. No previous AI red teaming experience is required.
